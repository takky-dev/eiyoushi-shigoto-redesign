# えいようしごと リニューアル案

[eiyoushi.shigotolink.com](https://eiyoushi.shigotolink.com/) を栄養士・管理栄養士専門の求人サイトへリニューアルするための実装案。3方向のデザインパターンをそれぞれ完全な静的ページとして実装しています。

## 見方

```
pattern-a/index.html   … 信頼のエディトリアル型（トップページ）
pattern-a/list.html    … 求人一覧（検索フィルター付き）
pattern-a/job.html     … 求人詳細
pattern-a/apply.html   … 応募する（5ステップの応募フォーム）
pattern-a/faq.html     … よくある質問
pattern-a/about.html   … サイトについて
pattern-a/terms.html   … 利用規約（サンプル、要法務確認）
pattern-a/privacy.html … プライバシーポリシー（サンプル、要法務確認）
pattern-a/contact-company.html … 掲載のお問い合わせ（企業向け）
pattern-b/ , pattern-c/ … 同じ9ページ構成をB・Cのデザインで実装
assets/img/            … 3パターン共通で使う写真
```

各パターンとも、トップページ→求人一覧→求人詳細→応募フォーム、まで実際にリンクをたどって遷移できます。

ローカルで確認する場合は、このフォルダ直下で以下を実行してください。

```bash
python -m http.server 8080
```

その後 `http://localhost:8080/pattern-a/` のようにアクセスすると各パターンを確認できます（`file://` で直接開くと `fetch` や相対パスの一部が制限される場合があります）。

## 前提：媒体型（求人メディア）であって、エージェント型ではない

最初のバージョンはレバウェル栄養士・栄養士転職ナビなど「アドバイザーが仲介する転職エージェント」を競合として参考にしていましたが、これは前提を誤っていました。`eiyoushi.shigotolink.com` は [シゴトLINK本体](https://shigotolink.com/) や [お仕事マッチ](https://oshigotomatch.com/) と同じ基盤（検索カードがヒーロー写真に重なる構成、「ピックアップ求人」「新着求人」という共通セクション名）の上に乗っている**媒体型（求人メディア）サイト**です。シゴトLINK本体のトップページには「2クリックでカンタン応募」と明記されており、求人詳細ページのCTAも「この求人に応募する」という直接応募ボタンでした。相談・ヒアリングを挟むエージェント型の導線ではありません。この実装は、その前提に合わせて作り直したものです。

## 3パターンの方向性

方向性の骨格（検索→一覧→詳細→直接応募）は3パターン共通です。違うのは基調色とビジュアルの温度感のみで、掲載する求人・カテゴリ・エリア・条件などのコンテンツは同一にしています。デザインの違いだけで比較できるようにするためです。競合のブランドカラーを `getComputedStyle` で実測したところ、各社は基調色をあえてズラし（ティール／ライムグリーン／青）、CTAボタンだけ暖色にするという共通ルールが見えたため、3パターンもその考え方を踏襲しています。

| パターン | コンセプト | 基調色 |
|---|---|---|
| A: 信頼のエディトリアル型 | 大きな写真1枚と余白で見せるミニマル構成 | ディープティール `#146356` |
| B: あたたかい親しみ型 | 丸ゴシック・チェックリストで柔らかい印象 | ライムグリーン `#6F9124` + オレンジ `#E2582E` |
| C: 栄養士ならではの遊び心型 | 「求人成分表示」という栄養成分表示のパロディで独自性を作る | ハーブグリーン `#2F6B4F` + オレンジ `#E08A2E`、寒色寄りのセージホワイト背景 |

## 求人一覧・求人詳細・応募導線について

- **求人一覧**（`list.html`）: キーワード・エリア・雇用形態に加えて、職種／施設種別／こだわり条件をチェックボックスのピルで絞り込める形にしています。件数表示＋ページネーションも設置済みです。
- **求人詳細**（`job.html`）: シゴトLINK本体の実際の求人詳細ページの構造を踏襲しています。
  1. 雇用形態バッジ・会社名・住所（ピンアイコン付き）
  2. 給与・エリアをまとめたハイライトボックス
  3. **「この求人のポイント」チェックマーク箇条書き**（3〜4点）
  4. **「キープする」（保存）＋「この求人に応募する」の2階層CTA**（直接応募）
  5. 業務内容・給与・勤務時間・休日・福利厚生などの詳細スペック表
  6. モバイルでは画面下部に同じCTAが常に固定表示される（スクロールしても消えない）
- **応募フォーム**（`apply.html`）: シゴトLINK本体で実際に「この求人に応募する」を最後まで押して確認した、**会員登録なしの5ステップウィザード**をそのまま再現しています。
  1. ご経験を教えてください（求人内容に応じたタイル選択）
  2. お持ちの資格を教えてください（タイル選択）
  3. ご希望の転職時期（タイル選択）＋ お住まいの都道府県（プルダウン）
  4. お名前・生まれ年
  5. 電話番号・メールアドレス・履歴書アップロード（任意）→ 応募完了
  各ステップで進捗（「あとNステップで完了！」）と、右側に応募先求人のサマリーを常時表示。ステップ1〜4の構成は実際の操作で確認済み、ステップ5（連絡先の項目）は一般的な応募フォームとして妥当な項目を補完しています（実サイトのバリデーションの都合で最終ステップまでは確認できませんでした）。
- **会員登録・ログインは存在しません**（シゴトLINK本体・お仕事マッチともにヘッダーに無し）。ヘッダーには検索求人数を除くとナビゲーションのみで、CTAボタンも設置していません。フッターの「企業の方へ」も、お仕事マッチの実ナビにあった「掲載のお問い合わせ」を採用しています。
- トップページには「ピックアップ求人」に加えて**「新着求人」セクション**を追加し、シゴトLINK本体と同じく求人の鮮度をアピールする構成にしています。

なお、求人一覧の「もっと見る」「求人の詳細を見る」は、デモの都合上すべて同じ `job.html` にリンクしています（実装時は求人IDでURLを分岐させてください）。

## 追加した情報ページについて

「選ばれる理由」を数値付きの箇条書きで深掘りしたうえで、応募サイトとして最低限あるべき5ページを新設しました。ナビゲーション・フッターとも、お仕事マッチの実際のグローバルナビ（求人を探す／よくある質問／お仕事マッチについて／掲載のお問い合わせ）に合わせています。

- **`faq.html`**（よくある質問）: 応募・求人掲載・個人情報の3カテゴリで計10問。トップページにも3問だけ抜粋したプレビューを設置し、「もっと見る」で全文へ遷移します。
- **`about.html`**（サイトについて）: サービスの特徴（媒体型・会員登録不要・掲載前確認）とおすすめの利用シーンを説明。
- **`contact-company.html`**（掲載のお問い合わせ）: 求人掲載を検討する企業向けの説明とお問い合わせフォーム（会社名・ご担当者名・電話番号・メールアドレス・ご相談内容）。
- **`terms.html`** / **`privacy.html`**（利用規約・プライバシーポリシー）: 一般的な条文構成のサンプルです。**公開前に必ず法務担当者の確認を受けてください**（ページ内にもその旨を明記しています）。

## 写真について

`assets/img/` の4枚はGemini生成の日本人モデル画像（ユーザー提供）です。

| ファイル | 用途 |
|---|---|
| `hero-consult.jpg` | パターンA・Cのヒーロー写真、パターンCの「求人成分表示」タグの背景 |
| `cat-hospital.jpg` | 病院・クリニックのカテゴリ写真、パターンBのヒーロー写真 |
| `cat-eldercare.jpg` | 高齢者・介護施設のカテゴリ写真 |
| `cat-schoolmeal.jpg` | 学校給食のカテゴリ写真 |

**未対応**: 「保育園・幼稚園」カテゴリの写真がまだありません。現状はアイコン表示のままです。以下のプロンプトで同じ縮尺（正方形構図・明るい自然光）の画像を追加生成し、`assets/img/cat-nursery.jpg` として配置後、各 `index.html` の該当箇所（`cat-icon` の中身）を他カテゴリと同じ形で差し替えてください。

> 日本の保育園の給食室で、白い調理服とマスクを着けた日本人栄養士が、彩り豊かな給食のトレーを並べている。明るく柔らかい自然光、清潔感のある雰囲気。正方形構図。

また、Gemini生成画像特有のクセとして、PC画面の文字や本の背表紙など細部の文字が崩れて見える箇所があります。現状の縮尺（サムネイル〜ヒーロー程度）では問題ありませんが、画像をトリミングして大きく見せる用途は避けてください。

## 実装時の注意点

- すべて素のHTML/CSSで、フレームワーク非依存です。既存の `eiyoushi.shigotolink.com` の実装スタックに合わせて、コンポーネント単位で移植してください。
- 検索フォーム・「求人を検索」ボタン・各種CTAは見た目のみで、実際の検索・送信処理は未実装です。
- 掲載している求人4件・統計数値（掲載求人数など）はすべて仮のサンプルです。実データに差し替えてください。
- モバイル幅（720px以下）ではハンバーガーメニューと画面下部固定のCTAバーに切り替わります。
- Googleフォント（Zen Kaku Gothic New / Zen Maru Gothic / Kaisei Decol / IBM Plex Mono）を使用しています。社内配信ポリシー上セルフホストが必要な場合は `<link>` タグをローカルフォントに差し替えてください。
